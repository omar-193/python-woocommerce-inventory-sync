# Security and Privacy Boundaries

This repository is a sanitized portfolio showcase. It must not contain:

- Company identifiers or proprietary business logic
- Production URLs, database names, table/view names, or internal IP addresses
- Credentials, API keys, usernames, or passwords
- Real SKUs, product/customer data, or production logs
- Local absolute paths or private endpoints

`.env.example` and `data/product_map.example.json` contain placeholders only.
The real production implementation remains private because it connects to
company systems and operational data.
